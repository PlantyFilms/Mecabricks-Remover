# Mecabricks-Remover
Removes Mecabricks files (e.g. nodes, materials, & textures) from your Blend file in the click of a button to be more shareable

(Due to the licensing restrictions of Mecabricks that aren't as talked about enough because they are not easily accessible and only show up exactly one time per user.)

For more, see here: https://mecabricks.com/en/forum/topic/59017 (because the only other place it's available in is a fourm post)
